# PAIDA — جعبه‌ابزار دیجیتال فارسی

PAIDA یک وب‌اپ سبک و واکنش‌گراست که ابزارهای کوچک و کاربردی را در یک فضای فارسی و یکپارچه جمع می‌کند.

## ابزارهای نسخه اول

- **متن‌یار:** شمارش کلمه، نویسه و خط؛ مرتب‌کردن فاصله‌ها و کپی متن
- **یادداشت سریع:** نوشتن و ذخیره خودکار یادداشت در حافظه محلی مرورگر
- **مرتب‌ساز JSON:** اعتبارسنجی، قالب‌بندی خوانا و فشرده‌سازی JSON
- **تایمر تمرکز:** تایمر ۲۵ دقیقه‌ای با شروع، توقف موقت و بازنشانی

## اجرا

فایل `index.html` را در یک مرورگر مدرن باز کنید. برای توسعه می‌توانید از افزونه Live Server در VS Code استفاده کنید.

## ساختار پروژه

- `index.html` — صفحه اصلی، کارت ابزارها و پنجره ابزارها
- `styles.css` — طراحی Modern Glass UI و چیدمان واکنش‌گرا
- `script.js` — جست‌وجو، فیلترها و منطق ابزارها

## حریم خصوصی و محدودیت‌ها

ابزارهای این نسخه در سمت مرورگر اجرا می‌شوند و برای استفاده از آن‌ها نیازی به حساب کاربری یا سرور اختصاصی نیست. یادداشت سریع در `localStorage` همان مرورگر ذخیره می‌شود؛ بنابراین با پاک‌شدن داده‌های مرورگر یا استفاده از دستگاه/مرورگر دیگر، ممکن است در دسترس نباشد. این نسخه همگام‌سازی ابری یا پشتیبان‌گیری بین دستگاه‌ها ندارد.

فونت Vazirmatn از Google Fonts بارگذاری می‌شود و در صورت نبود اینترنت، فونت جایگزین سیستم استفاده خواهد شد.
