# Blank Web Starter

یک قالب وب فارسی، مینیمال و واکنش‌گرا برای شروع پروژه‌های جدید.

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای توسعه راحت‌تر می‌توانید از افزونه Live Server در VS Code استفاده کنید.

## ساختار
- `index.html` — ساختار صفحه
- `styles.css` — ظاهر، چیدمان و واکنش‌گرایی
- `script.js` — تغییر پوسته و تعامل‌های ساده

## امکانات
- پشتیبانی از زبان فارسی و راست‌چین
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- حالت روشن و تاریک با ذخیره انتخاب کاربر
- انیمیشن‌های ظریف و رعایت تنظیم کاهش حرکت
- بدون فریم‌ورک یا وابستگی JavaScript خارجی

فونت Vazirmatn از Google Fonts بارگذاری می‌شود؛ در صورت قطع اینترنت، فونت جایگزین سیستم استفاده خواهد شد.
